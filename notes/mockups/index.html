Agentic SE Course v2: mockups

High-fidelity static mockups of the v2 site specified in notes/design.md, built on the v1 typefaces, column, greys and accent, with v1's real course titles and links. Each page is shown live at desktop width (1280 px, scaled to fit) and phone width (375 px). Scroll inside a frame, flip the track switch, tick items off, take the self-check or log an estimate: progress is saved in your browser and shows up on My progress. Session dates appear only after a cohort calendar is loaded. Pages follow your light or dark setting.

Numbered markers on the frames map to the decision lists under each page.

Week 1 self-check

#/week/1/check · week-1-check.html

Implements design.md §3 "Self-check": five retrieval questions answered from memory, with the answer and its source shown after each attempt. Questions are drafted from the Best Practices page and the two course descriptions. Interactive with plain JavaScript; nothing is stored. Also §4 "Type, links and headings" (h1 page, h2 per question) and "Motion and targets".

Open week-1-check.html

  1. Answer from memory first, then open the answer: testing beats restudying. roediger2006; agarwal2021
  2. Confidence before the reveal. Each question asks how sure you are (guess to certain) before the answer opens; confident errors are flagged gently, since they are the ones most worth correcting. butterfield2001; metcalfe2017
  3. Feedback with a source. Choice questions state the pick in words and tag the right option with text, not colour alone; every answer links the section it comes from. hattie2007; w3c2024wcag22 SC 1.4.1
  4. Saved in this browser: every try, with answers, confidence and self-scores, goes to My progress and into the export. No account, no server. notes/progress/README.md

My progress

#/progress · progress.html

The learner's own record, drawn from what they ticked, logged and answered on the week pages: minutes done against planned by week, self-check scores and a confidence calibration chart, logged minutes against the page estimates, the benchmark estimates, the cohort calendar, and export, import and reset.

Open progress.html

  1. Bars on one scale for completion by week and for minutes logged against estimates; every chart has a "Show as table" alternative. cleveland1984; heer2010; w3cwaicomplex
  2. Calibration: choice questions right at each confidence level, so learners see whether "certain" means right. butterfield2001; metcalfe2017
  3. Export for the course owner. Download JSON on the real site; inside this artifact downloads are blocked, so Copy JSON and a read-only JSON box are the fallback. The file carries no name unless the learner types an alias. notes/progress/README.md
  4. Import and reset. Merge or replace from a file or pasted JSON, with validation errors shown; clearing progress asks for confirmation in the page. w3c2024wcag22 SC 3.3.4
  5. No comparisons between learners: no streaks, points or cohort leaderboards. matcha2020; jivet2017
