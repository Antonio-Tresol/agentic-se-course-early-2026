Factory skills live in factory/.claude/skills/<name>/SKILL.md and load with --add-dir factory (Extend Claude with skills (opens in a new tab)). lanorme's CI requires every skill under the root .claude/skills/ to have a synced copy in .agents/skills/, so this location keeps factory skills clear of that check and out of any upstream pull request. The observer may write only factory/.claude/skills/review/SKILL.md. Agent teams play no part, since teammates do not spawn under -p (Orchestrate teams of Claude Code sessions (opens in a new tab)). Managed Code Review and routines are optional upgrades for learners whose plans include them.

Codex scans .agents/skills in each directory from the working directory up to the repository root, and --add-dir grants extra writable directories without loading skills (Build skills (opens in a new tab)). Success criterion

The capstone is done when:

  • three or more issues on the fork reach a pull request that passes lanorme's CI and waits only on your approval;
  • one of them goes through the spec path, and one replays the Week 3 issue from the recorded base commit;
  • no human starts a stage;
  • the observer loop has made at least one accepted change to the review skill, and a rerun shows its effect;
  • the report sets the replayed issue's human minutes and cost beside its Week 3 figures, gives per-change figures for the others, counts failed runs, and reports setup hours separately.

Before the first run, add the API key or CLAUDE_CODE_OAUTH_TOKEN secret and create the factory labels on the fork. Open at most one pull request upstream, by hand.
