Week 1

One Coding Agent

Track

This week is about getting your hands dirty. You install a coding agent, work through two structured courses, and learn the established best practices for steering it effectively.

Time budget

Pre-work: 172 min185 min core. No optional items, no pre-work activity.

By the end of this week you can

  1. Take a small change in an unfamiliar repository from prompt to verified diff, giving the agent a check to run: a test, a linter or a build.

    Self-check, question 1

  2. Choose a permission mode for a task and say what the agent may do in that mode without asking.

    Self-check, question 5

Live session

Length
60 min

We debrief on the courses, then break into pairs for benchmark estimation.

Five-minute retrieval opener

We start on paper, without notes: three short questions, two on this week's pre-work and one from Week 0. Then we compare answers before moving on.

Benchmark Estimation

Can you judge how much work an agent can complete on its own today? You test your judgement on two tasks from public coding benchmarks and see the published results only after you commit to an answer.

  1. Enter your pair number to get your two tasks, one for each round.
  2. Run the task's setup commands and give your agent the starter prompt.
  3. Read the agent's answer and probe it with follow-up questions, for about nine minutes.
  4. Save your estimate: the minutes an experienced engineer would need, complexity, specification quality and how many published agent runs passed.
  5. Repeat for round 2, then reveal both tasks when the facilitator calls it.

Starter prompt

Help us scope this task before anyone writes code. Read TASK.md (or instruction.md). Do not edit any file, do not search the web, and do not open README.md, task.toml, solution/, tests/ or any linked pull request. Then (1) list the files and functions involved, one line each; (2) describe what a complete solution must change; (3) name the two riskiest unknowns; (4) say how you would check the solution works. Keep the answer under 300 words.
