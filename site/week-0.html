Install your agent

We install together in the session. If you can, install before it, so the session time goes to your first task. You need a terminal (macOS, Linux or WSL), git, a GitHub account and the account you will use with your agent.

Practice Required

Install Claude Code

macOS, Linux or WSL

curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell

irm https://claude.ai/install.ps1 | iex

Homebrew

brew install --cask claude-code

Run it in any repository, and log in on first use

cd your-project && claude

Next week: estimate real benchmark tasks with your agent

Bring the agent you install today. In pairs, you look at the latest numbers on the hardest public software-engineering benchmarks, then give your agent ten minutes to scope a real task from one of them. You estimate how long it would take an experienced engineer, how complex it is and how well specified, and only then see the published answers.
