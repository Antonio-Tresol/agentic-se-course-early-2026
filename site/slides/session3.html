No Vibes Allowed · Key Idea

Intentional Compaction

Attention degrades: Crowded context introduces noise and confusion.
Crystallise state: Distil research into clear files like specs/<issue>.md.
Fresh sessions: Implement from the spec alone, leaving history behind.
RPI to QRSPI · Key Idea

Research Before Planning

Bad plans multiply waste

A bad line of code is one bad line. A bad line in a plan can produce hundreds, and a bad line in research thousands.

Ground in real code

Inspect existing files, test fixtures, and interfaces before committing to a design. Never let the agent plan from prompt assumptions alone.
