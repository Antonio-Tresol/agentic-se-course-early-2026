5:00 to 15:00 · Key Idea

Intentional Compaction

Attention degrades: crowded context introduces noise and confusion.
Crystallise state: distil research into a file such as specs/<issue>.md.
Fresh sessions: implement from the spec alone, leaving history behind.
5:00 to 15:00 · Key Idea

Research Before Planning

Bad plans multiply waste

A bad line of code is one bad line; in a plan, hundreds; in research, thousands.

Ground in real code

Inspect existing files and interfaces before designing.
