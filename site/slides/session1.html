14:00 to 16:00 · Pairs & Rules

Rules for the Agent

Allowed: read and run code to inspect the project.
Forbidden: editing files or searching the web.
Never open: README, task configs, solution, tests or the linked pull request.

14:00 to 16:00 · Question & Scales

The Scoping Question

How many minutes would an experienced engineer, new to this repository, need without AI to pass the tests?

Complexity (1 to 5)

1: one location.
3: several files or subtle logic.
5: days of expert work.

Specification (1 to 5)

1: goal unclear.
3: edge cases left to judgement.
5: precise to names and errors.

Then predict how many published agent runs passed. Tasks 1 to 4 only.
