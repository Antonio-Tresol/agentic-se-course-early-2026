Benchmark Caveats

Pro v1: ~30% of public tasks broken; OpenAI withdrew recommendation.
Terminal-Bench: Scores compare only within versions; 4.0 added 8h timeouts.

14:00 to 16:00 · Pairs & Rules

Rules for the Agent

Allowed: Read and run code to inspect the project.
Forbidden: Editing files or searching the web.
Hold back: Never open README, task configs, solution, tests, or the linked pull request.

Copy the starter prompt from the week page.

Activity · Question & Scales

The Scoping Question

How many minutes would an experienced engineer, new to this repository, need without AI to pass the tests?

Complexity (1-5)

1: Single guard clause.
3: Multi-file subtle logic.
5: Multi-day reverse engineering.

Specification (1-5)

1: Ambiguous or contradictory.
3: Clear core, fuzzy edges.
5: Exact behaviour and errors.
