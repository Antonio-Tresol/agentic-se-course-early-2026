Invariant 1 of 6

Context Is the Only Lever

LLMs are stateless. Tokens in context determine next tokens.

Context priorities
1Correctness: wrong facts mislead.
2Completeness: missing facts cascade.
3Noise: surplus tokens degrade attention.
Trajectory

Output quality ≈ (correctness × completeness) / (noise + size).

Debate 3 · Work structure

Vertical Slices or Horizontal Layers?

Horizontal

Migrations, then services, then UI. Nothing runs end-to-end until the end.

Vertical

Thin slice with mocks first, then real DB. Tests run at each seam.
