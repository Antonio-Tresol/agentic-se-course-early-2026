Layer 2 · Subagents

Subagents: Isolated Context

Context protection: Long research runs flood the window with file contents.
Independent workers: Subagents explore, test, or review in fresh sessions.
Distilled output: Only the final summary returns to the main conversation.

Use subagents when exploring large codebases or conducting separate code reviews.

Layer 3 · MCP

Model Context Protocol

Open Standard

Connects agents to databases, issue trackers, internal APIs, and local developer tooling without proprietary glue code.

Transports

stdio for fast local CLI processes.
SSE / HTTP for remote services.
Credentials stay securely with the server.

Anthropic Engineering

Context Engineering

Attention is finite: Tokens in context compete for attention; noise degrades output.
Trajectory bias: If a session contains failed edits, the agent tends to repeat them.
Intentional compaction: Clear context between unrelated tasks; write specs before coding.
20:00 to 55:00 · Activity

Skill-Building Sprint

In pairs. Write a skill, swap it, and test its trigger.

1Pick a repository: One from the Week 1 benchmark tasks, or your own project.
2Author a skill: Write a SKILL.md for a repeating check or workflow.
3Swap and test: Verify that it triggers when needed and stays silent otherwise.
Sprint Step 1 · Authoring

Writing an Effective SKILL.md

Frontmatter description: Explain exactly when the agent should invoke it.
Prerequisites & context: List the files or commands the skill relies on.
Deterministic steps: Provide ordered instructions and error checks.
Success criteria: Give the agent a command to verify its work.
Sprint Step 2 · Testing

Testing Trigger Precision

Positive test

Prompt your agent with a task the skill was designed for. Does the agent invoke the skill automatically?

Negative test

Prompt with an adjacent but unrelated task. Does the skill stay quiet, avoiding context pollution?
