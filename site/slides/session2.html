5:00 to 20:00 · Both Tracks

Context Engineering

Context rot: recall declines as tokens in context grow; attention is finite.
Compaction: near the limit, summarise and continue in a new window.
The risk: compact too hard and subtle context that matters later is lost.
20:00 to 55:00 · Sprint · Authoring

Writing an Effective SKILL.md

Description: say exactly when the agent should invoke it.
Context: list the files or commands the skill relies on.
Steps: ordered instructions with error checks.
Success: give the agent a command to verify its work.
20:00 to 55:00 · Sprint · Testing

Testing Trigger Precision

Positive test

Prompt a task the skill was written for. Does the agent invoke it?

Negative test

Prompt an adjacent, unrelated task. Does the skill stay quiet?
