The 4D Framework · Dakan & Feller

The 4D Cycle

Delegation

What is worth delegating, and how do we divide the work?

Description

State requirements, context, and clear acceptance criteria.

Discernment

Evaluate outputs critically for correctness and design quality.

Diligence

Take full ownership of the final code and its behaviour.

Delegation → Description → Discernment → Diligence → repeat

Why This Matters

Discernment

Read what the agent wrote before you rely on it. Horthy's remedy is to turn human review back on.

Diligence

You own what ships, including code you did not type.

Agency raises the stakes. You vouch for code you did not type. Discernment and diligence are essential.

Install Your Agent

Both tracks supported throughout the course: Claude Code and OpenAI Codex.

Claude Code Track

Install Claude Code

# macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows PowerShell
irm https://claude.ai/install.ps1 | iex

# Homebrew
brew install --cask claude-code

# Run in any repository
cd your-project && claude

Sign in on first use. Docs: code.claude.com/docs

Install Codex
