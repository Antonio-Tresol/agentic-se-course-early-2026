Install Claude Code

Terminal

# macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows PowerShell
irm https://claude.ai/install.ps1 | iex

# Homebrew
brew install --cask claude-code

# Run in any repository
cd your-project && claude

Desktop app

  1. Download ClaudemacOS, Windows or Linux (beta)
  2. Sign in
  3. Open the Code tab
